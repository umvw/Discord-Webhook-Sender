# Discord-Webhook-Sender  
  
This is the **Discord Webhook Sender**, or also called **DWS**  
![Logo](https://cdn.discordapp.com/attachments/1509495030791012496/1530779759296909432/dwsicon.png?ex=6a66d13f&is=6a657fbf&hm=6dd9ed6b2be9b9ad6b12e1eb1ad6d832558610c962c0b384827de79c90592e6b&)  
This was completely made with HTML and then compiled into Electron via NPM.  
I made this really just for personal use but then also compiled for easier use.  
  
## How it works  
  
All you have to do is just open the file and your done!  
Though since i compiled via electron, it will take a few seconds to open.
